# Specification

## Summary
**Goal:** Add the True Origin Exports company logo to the navigation bar and footer of the website.

**Planned changes:**
- Save the uploaded logo as a static asset at `frontend/public/assets/generated/logo.png`
- Replace or accompany the text-based brand name in the navigation bar with the logo image, positioned on the left side, sized ~40–48px tall
- Ensure the logo is visible in both the transparent (top of page) and solid (scrolled) nav states
- Add the logo to the site footer alongside the existing brand information
- Make the logo clickable to scroll back to the home/top section

**User-visible outcome:** The True Origin Exports logo appears in the navigation bar and footer, replacing the text-only brand name with the visual logo.
